# Reelsi - optional dependencies.

# Each one enables EXACTLY ONE feature; everything else keeps working. They can
# be installed one by one: if rotoscoping is not needed, there is no point in
# pulling onnxruntime.
#
# What exactly fails without each one -  python reelsi/doctor.py
#
#   pip install -r requirements-optional.txt

# Russian CTC model: word-level cuts in GigaAM mode and subtitles with its
