# ROADMAP — открытые направления и история решений

## Ротоскоп — сделано
Автоматизирован через модуль `core/roto.py` (локальная GPU-модель Robust Video Matting, RVM). Вырезает альфа-маску персонажа для After Effects. Подробности и инварианты — в `docs/ARCHITECTURE.md` (строка `core/roto.py` в таблице модулей и пункты в подводных камнях).

## Мелкие правки (сделаны)
- Цензор считается по полному списку слов (интро-слова тоже звучат) — `censor_source`.
- Поп текста сдвинут на +4 кадра.
- Конец слова-титра обрезается по началу следующего (мелкие «и/в» не накладываются).

## ИИ-разметка — пакет `core/aicut/`
Вызовы LLM вынесены в пакет `core/aicut/` (`python -m core.aicut`): разметка жёлтых слов, подбор и генерация вставок, хук и интро. Модели и ключи настраиваются через профили провайдеров в UI (⚙ → «Модели и подключения», `ai_config.json`). Архитектура и контракты — в `docs/ARCHITECTURE.md`.

## Стили-пресеты (styles.py + UI «Стиль»)
Пресет = dict (шрифт базы/выделения, цвет, звуки перехода/попа, музыка-dB, рото, intro_mode).
Встроенные: **`base`** (дефолт, = прежний стиль) и **`geologica`** (Geologica
Regular/SemiBold, кремовый акцент, всегда рото). Пользовательские шаблоны — JSON в
`reelsi/styles/*.json` (кнопка «Сохранить как шаблон»), не хардкодятся. «кастом» в селекторе
редактирует все поля. Проброшено в оба эндпоинта сборки и в набор.

Реализовано сейчас (безопасно параметризуется): шрифт текста, шрифт+цвет выделения (болд через
жирный PostScript-вариант), звук перехода/попа и видео-переход (замена файла на прежней механике),
глушение музыки, дефолты рото (вкл/низ%/устройство), intro_mode.

Осталось по `geologica` (структурно, нужен тест в AE — отдельная доработка):
- видео-переход: 2 слоя `transitions.mov` + эффект **Luma Key** (Key Type 2, Threshold 29) +
  поворот 90° у второго, звук `Cinematic Woosh.mp3` — сейчас заменяется только файл/звук на
  одиночной Add-механике базового стиля.
- интро: **3 отдельных компа** («текст интро» 1/2/3), в каждом слова разложены ВРУЧНУЮ по
  свободным позициям (не авто-стопка по центру), размер 140, выделение ExtraBold кремовый.
- фотовставки: немного другие анимации/эффекты, ротоскоп ОБЯЗАТЕЛЕН (и на видео, и на фото).
  СДЕЛАНО (интро): рото в окне интро идёт по ПОКАЗЫВАЕМОЙ камере — cam1 в разрывах + cam2-перебивки,
  бутербродом над слоем интро-текста (`_span_roto_plan`/`_cam_overlaps`; ROTO-энтри с `ci`+`intro`,
  маски из исходника своей камеры, JSX `CAM[ci]`/`nulls[ci]`). Нужен тест в AE.
  ОСТАЛОСЬ: рото на видеовставках; рото ВСТАВОК тянуть через каты Премьера (сейчас по одному клипу cam1).
- обрезка звуков (поп/переход) ползунками с прослушиванием — в кастом-стиле.

## Путь: уроки video-use (2026-07-15)

По мотивам https://github.com/browser-use/video-use — агентная монтажка: LLM читает
пословный транскрипт (не видео) → EDL → ffmpeg-рендер → self-eval (до 3 итераций);
визуальный композит (кадры+волна+слова) генерится ТОЛЬКО по требованию для спорных мест;
аудио-фейды на каждом срезе; сессионная память project.md. Мы архитектурно уже совпадаем
(транскрипт-driven omni_cut, sidecar-файлы, виртуальный EDL в `/api/aicut_preview`) —
ниже 4 этапа, которых не хватает. Ограничение: один ПК, 16 ГБ VRAM — всё дорогое
отключаемо, новые GPU-шаги следуют паттерну свопа (`aicut.unload_ours` /
`transcribe.release_model` / subprocess как omni_asr): две модели одновременно не живут.

### Этап 1 — аудио-фейды ~10мс на стыках сегментов

**Статус: сделано** (ключ `audio_fades` в `styles.py:119`, генерация keyframes в `core/xml2ae/build.py:2302`).

Сейчас склейки жёсткие (в `core/xmlbuild.py` только статический гейн Audio Levels) — щелчки
на границах. ВАЖНО: финальный рендер — After Effects, поэтому фейды должен применять AE.

- Главное место: `core/xml2ae/build.py` / шаблон `AE_FULL` — на аудио каждого клипа камеры ставить
  keyframes «Audio Levels»: -inf(≈-48dB) → рабочий уровень за ~10мс (0.6 кадра @60fps;
  AE поддерживает суб-кадровые времена ключей), симметрично на выходе. Границы берутся
  из распарсенного ФИНАЛЬНОГО XML → фейды автоматически следуют за любой ручной правкой
  монтажа в Premiere.
- Опционально: те же keyframes в `core/xmlbuild.py` (FCP7 `<parameter>` level поддерживает
  `<keyframe>`) — чтобы и в Premiere при ручной чистке звук был чистый. Проверить импорт.
- Тумблер: флаг стиля `audio_fades` (вкл по умолчанию). Цена: ~0 (генерация ключей).
- Критерий: рендер AE без щелчков на стыках; ключи видны на аудио-слоях.

### Этап 2 — самопроверка нарезки + черновой mp4 как шаги пайплайна

**Статус: сделано частично** (черновой рендер `draftrender.py:render_draft` и `/api/draft_render` работают; `core/selfcheck.py` есть в классическом пути, но в GigaAM отключён по умолчанию — `selfcheck=False` в `api/jobs.py`).

> **Статус самопроверки на 2026-08-11: ВЫКЛ и убрана из UI.** Основная нарезка
> — GigaAM, а в нём `core/omni_cut.py` возвращается из ветки `gigaam_path` задолго до блока
> селфчека: галочка «самопроверка» и селект «Движок самопроверки» не делали ничего.
> Внутренняя петля самопроверки `gigaam_cut` (`max_iter`, GigaAM переслушивал вырезку
> и черновик) выпилена 2026-08-10 — по замерам она делала результат хуже. Нынешняя
> нарезка без самопроверки устраивает, поэтому контролы сняты, а `selfcheck` по
> умолчанию `False` (`api/jobs.py`). Код пути жив в `core/selfcheck.py` и работает у старого
> пути из CLI. **Вернуть — осознанная задача этого этапа: сначала решить, что
> именно переслушивает GigaAM-путь, потом возвращать галочку.** Черновик mp4
> (ступень `draft`) к этому отношения не имеет и работает в обеих ветках.

Порядок на каждый клип (чекбоксы в webui):

1. **self-check** (сразу после нарезки, ДО рендера — черновик рендерится исправленным):
   склеить keep-аудио (механика уже есть в `/api/gen_subs`) → Whisper → сравнить с
   ожидаемым текстом (`<src>.words.json` минус вырезанные интервалы) → список «слово
   обрезано на стыке t» → авто-расширить ТОЛЬКО проблемные границы (+0.05..0.1с, правка
   keep в `.project.json` + пересборка XML) → 1 повтор проверки (self-eval как у
   video-use, но max 1 итерация). Отчёт в `.cuts.json`/лог.
   Цена: ~0, если совмещать с Whisper-прогоном генерации субтитров (сравнение текста —
   миллисекунды); +1-3 мин ТОЛЬКО при найденных проблемах. VRAM: внутри существующей
   Whisper-фазы.
2. **draft_render** (финал нарезки клипа): ffmpeg-рендер `<stem>.draft.mp4` по
   виртуальному EDL. Реюз: парсер EDL из `/api/aicut_preview` (api/editor.py) вынести в
   функцию — segs (камера+исходное время), audio, words уже считаются. Рендер =
   trim+concat сегментов камер (NVDEC+NVENC, 720p) + слова через ass/drawtext.
   Черновик = «посмотреть глазами без Premiere» + вход для Omni-оценки (этап 4).
   Плюс кнопка «Черновик mp4» в webui — ручной перерендер после правок в редакторе.
   Цена: +~1-2 мин на 6-мин ролик; ~1 ГБ VRAM (LLM/Whisper к этому моменту выгружены).
- Критерий: инжектированный «плохой» рез (граница внутри слова) находится и чинится
  автоматически; рядом с XML лежит `<stem>.draft.mp4`.
