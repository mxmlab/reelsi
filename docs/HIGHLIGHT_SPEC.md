# Жёлтые выделения субтитров — спецификация

Восстановлено из реального проекта (дамп `tools/ae_inspect.jsx` → `1.json`),
эпизоды сопоставлены по транскриптам (`Reelsi_out/*.words.json`).

## Базовый стиль (все слова)
- Шрифт: `SFPro-CondensedSemibold`, по центру.
- Размер: **140** (в проекте это 97 с масштабом ~140 % — эквивалент; мы печём 140 напрямую).
- Цвет: белый `[1, 1, 1]`.
- Появление: хард-кат (без анимации), без звука.
- Якорь позиции (одиночное слово): X = W/2, Y ≈ **0.5964·H** (=1145 при 1920).

## Выделенное слово
- Всё то же (размер 140, шрифт, центр), но:
- Цвет: жёлтый **`[1, 0.9176, 0]`** (RGB 255/234/0).
- Анимация «slide-up»: Position выезжает снизу вверх на ≈0.064·H (~123 px при 1920)
  за **~0.35 с**. Scale не трогаем.
- Анимация Opacity **0 → 100** на том же окне ~0.35 с.
- Ease обеих анимаций: **cubic-bezier(0.35, 0.01, 0.10, 0.99)** —
  в терминах AE: key1 out-influence 35, key2 in-influence 90, speed 0
  (тот же безье, что у зума камеры; `1−0.10 = 0.90`).
- Звук: поп `assets → highlight_pop` (`4 type & delete.wav`) в момент появления (startTime = start слова).

## Стопка (подряд идущие выделенные слова)
«Подряд» = соседние слова в порядке субтитров, оба выделены.
- Ряд r (0-based): Y = ROW1 + r · STEP, где ROW1 ≈ 0.5964·H, STEP ≈ 0.06224·H (~119.5 px).
- Каждое слово выезжает в свой ряд со своим start; **общий out** = конец последнего слова связки
  → вся стопка держится вместе и исчезает разом.
- Пример из C1221: «ФИЗРАСТВОР»(ряд0)+«С САХАРОМ»(ряд1); «ОТЕК»+«ЛИЦА»; «не»+«досыпали».

## Красный акцент (на будущее, не реализуем сейчас)
Тёмно-красный `[0.6863, 0.1216, 0.1216]` — негативный смысл («ПОД БЕШЕНЫЕ ПРОЦЕНТЫ»).

## Где реализовано
- `core/xml2ae/build.py` — `to_ae_full(..., highlights=set_of_indices)` строит слои с учётом стиля/стека/попа.
- UI — панель «Слова» в предпросмотре: клик по слову = жёлтое; индексы уходят в `/api/set_yellow`.
- Индексы — 0-based позиции слов в отсортированном по времени списке субтитров (как их видит `parse_full`).
