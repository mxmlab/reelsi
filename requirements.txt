# Reelsi - core dependencies.
#
# Three files, so users don't have to pull what they don't need:
#   requirements.txt           - this one: Reelsi won't work without it
#   requirements-optional.txt  - individual features; everything else stays alive
#   requirements-dev.txt       - tests and linter, not needed by users
#
# Check what is installed and what will fail:  python reelsi/doctor.py
#
# IMPORTANT: torch is installed SEPARATELY and FIRST - pick the build for your
# GPU at https://pytorch.org/get-started/locally/ . torch is intentionally
# unpinned here: PyPI ships a CPU build, and everything GPU-bound
# (Omni, GigaAM, roto, forced-align) would run tens of times slower. Tested pair:
#   pip install torch==2.11.0 torchaudio==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cu126
# torchaudio must match torch exactly (it is a C++ extension built per torch). The pair
# is 2.11.0 and not newer on purpose: torchaudio 2.11.0 is the last torchaudio release, and
# there is no torchaudio build for torch 2.12 or later. GigaAM (MelSpectrogram, resample)
# and our forced alignment (forced_align, merge_tokens) need torchaudio, so the pair cannot
# move up until torchaudio ships a build for it. torchaudio.load is not called anywhere in
# Reelsi any more: audio for alignment and CTC is read by soundfile (core/falign.load_wav_16k),
# so the torchcodec package that torchaudio.load requires from 2.9 is not needed.
# Once torch and torchaudio are installed, the unpinned torchaudio line below is satisfied
# by the installed build and pip does not upgrade it.
#
# Everything else carries an UPPER bound on the major version: a bare `>=` lets
# pip install a fresh release that breaks the subtitle step on a clean install
# (librosa 1.0 dropped the audioread fallback, PyAV 19 dropped
# `metadata_errors`) - exactly what the owner's already-pinned machine never saw.
torch
torchaudio
# needed by rotoscoping (RVM via torch.hub)
torchvision>=0.20

# --- core ---
# web UI (webui.py) and /api/*
flask>=3.0
numpy>=1.26,<3
# camera sync (cross-correlation), VAD
scipy>=1.11
soundfile>=0.12,<1
# SSM repeat detection, resampling
librosa>=0.10,<1.0
# interactive CLI (reelsi.py)
questionary>=2.0

# --- speech recognition ---
# default subtitle engine
faster-whisper>=1.0,<2
# PyAV is faster-whisper's decoder: it imports av even when handed a float32
# array. 19.0 removed the `metadata_errors` argument that faster-whisper 1.2
# still passes, so every path-based call raises TypeError - keep it below 19.
av>=12,<19
# Qwen2.5-Omni; if Omni fails to load, install from git:
#   pip install git+https://github.com/huggingface/transformers
# 5.x needs torch >= 2.6 at import (utils/import_utils.py calls torch.accelerator).
# Floor 5.10.1: the youngest 5.x with no pip-audit advisories (5.9.0 has PYSEC-2026-3929).
# Note: transformers 5.10.1 itself is clean, but the torch 2.11.0 pair above has one advisory
# in pip-audit (PYSEC-2025-194 / CVE-2025-3000, torch.jit.script, fixed in torch 2.13; Reelsi
# does not call torch.jit.script); that trade-off is recorded in CHANGELOG.
transformers>=5.10.1,<6
accelerate>=1.0
huggingface-hub>=0.26
# audio/video preprocessing for Qwen2.5-Omni
qwen-omni-utils>=0.0.9

# --- graphics and inserts ---
pillow>=10.0
# reading PostScript names of installed fonts
fonttools>=4.50
# media pool records in .drp (DaVinci Resolve), see DRP_SPEC.md;
# stdlib zstd only from Python 3.14, we use 3.10
zstandard>=0.22

# --- outside pip ---
# ffmpeg - must be on PATH (decode/encode; NVENC/VideoToolbox/AMF are picked up
# automatically, see docs/PLATFORMS.md).
# SF Pro font - needed by Premiere for subtitles from refblobs.json (see README).
