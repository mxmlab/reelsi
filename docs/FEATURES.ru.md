# Все возможности по шагам

Reelsi — локальный помощник монтажа говорящей головы. Этот документ проходит по мастеру
из трёх шагов и перечисляет все возможности: что делает каждая, где живёт в интерфейсе,
как ей пользоваться и что стоит денег.

English version: [docs/FEATURES.md](FEATURES.md).

## Как устроено

Интерфейс — один мастер из трёх шагов: **Нарезка** → **Разметка** → **After Effects**,
плюс окно настроек и отдельная вкладка «Видео». Всё тяжёлое считается на вашей машине:
распознавание речи, синхронизация камер, детектор вздохов, ротоскоп и черновой рендер.

Через API уходит только текст: текстовая LLM решает, что вырезать, какие слова
подсветить, где стоят вставки и что говорит интро. Эта же LLM умеет работать локально
в LM Studio или Ollama. Генерация картинок и видео всегда идёт через API провайдера.

## Перед началом

### Раскладка рабочей папки

Держите репозиторий в одной папке рядом с материалом. Результаты Reelsi пишет рядом с
материалом, поэтому мастеру достаточно знать, где лежат папки камер.

```
моя_папка/
├── reelsi/            ← этот репозиторий
├── камера1/           ← видео с камер
├── камера2/
├── music/             ← скачанные треки (необязательно)
└── Reelsi_out/        ← нарезки и сайдкары
```

**Где:** шаг 1 › **Папка проекта (где камеры)**
**Как:** 1. Положите репозиторий рядом с материалом. 2. Задайте папку проекта.
3. Нажмите **Пересканировать папки** — Reelsi покажет найденные папки камер.
**Настройки:** **Папка результата** — куда падают нарезанные XML и их сайдкары. Папка
для собранных `.jsx` задаётся на шаге 3.
**Code:** `templates/index.html:52`, `api/files.py:30`, `webui.py:81`

### Профили спикеров

Профиль спикера — это «кто в кадре» как набор настроек: свои папки, свои пороги нарезки,
свой стиль AE по умолчанию и свои подсказки ИИ.

**Где:** шаг 1 › **Спикер** (карандаш — правка, плюс — новый), и то же окно из строки
клипа на шаге 3.
**Как:** 1. Нажмите плюс рядом с селектором **Спикер**. 2. Заполните имя, папку
результата, папку для `.jsx` и папку вывода рендера. 3. Выберите стиль AE по умолчанию
и напишите подсказку ИИ, если она нужна. 4. Сохраните.
**Настройки:** пороги нарезки (тишина, голос, запас вокруг слова, дыра без речи и
остальные) лежат на свёрнутой панели **Калибровка — правит ассистент**; у детектора вздохов свои пороги
реза и метки. Приписки к промптам генерации картинок и видео — в том же окне, там же два
слота подложки — **Подложка: приписка к промпту 1/2**: их берут вставки с галкой **на
подложке** вместо обычных слотов.
**Ограничения / цена:** профиль — обычный JSON в `speakers/`, папка в гит не попадает.
Стиль в профиле — значение по умолчанию: на шаге 3 стиль всегда можно поменять.
**Code:** `core/speakers.py:29`, `core/speakers.py:68`, `api/presets.py:85`,
`templates/index.html:570`

### Профили ИИ-провайдеров

Профиль — это один провайдер плюс одна модель плюс ключ. Шаги мастера выбирают, какой
профиль на каком шаге работает.

**Где:** ⚙ в шапке › **Подключения**.
**Как:** 1. Откройте ⚙ и выберите или заведите профиль. 2. Выберите провайдера и
модель. 3. Вставьте API-ключ и нажмите **Проверить**. 4. Нажмите **Сохранить**.
**Настройки:** поддерживаются LM Studio и Ollama (локально), CommandCode, Anthropic,
OpenRouter, DeepSeek, Groq и любой OpenAI-совместимый адрес со своим Base URL. Ключ можно
написать как `env:ИМЯ_ПЕРЕМЕННОЙ` — тогда он не попадает в `ai_config.json`. Для шлюзов
есть дополнительные заголовки. Возможности модели (уровни размышлений, temperature,
кэширование) берутся из открытого каталога models.dev, кэш на диске обновляется раз в
сутки.
**Ограничения / цена:** ключ хранится только на сервере и отдаётся в браузер маской.
Текстовые вызовы стоят копейки; картинки и видео провайдер считает по выбранной модели.
Локальные провайдеры бесплатны.
**Code:** `core/aicut/config.py:41`, `api/ai.py:153`, `core/aicut/catalog.py:1`,
`templates/index.html:890`

### Каталог моделей и статистика вызовов

**Где:** ⚙ › **Подключения** › **Диагностика вызовов ИИ**; список моделей — в поле
**Модель** на той же вкладке.
**Как:** 1. Нажмите **Обновить список**, чтобы спросить у провайдера его модели.
2. Откройте диагностику, чтобы увидеть, во что обошлись прошлые вызовы.
**Настройки:** панель группирует вызовы по модели, шагу и уровню «ума» и показывает
медианы токенов, доли размышлений и времени. Ошибки считаются отдельно.
**Code:** `api/ai.py:524`, `api/ai.py:803`, `core/aicut/config.py:38`,
`core/aicut/catalog.py:22`

### Генерация картинок и видео: что встроено

Локальные генераторы картинок и видео в код не встроены. Генерация идёт в image-модель
или видео-модель через API провайдера. Проект открытый, поэтому подключить свой
локальный бэкенд может любой: точки расширения — `core/aicut/images.py` и
`core/aicut/video.py`.

## Шаг 1 — нарезка

### Материал с гугл-диска

**Где:** шаг 1 › **Получить материал с Google Drive** (свёрнутый блок сверху).
**Как:** 1. Вставьте ссылку в поле **Ссылка**. 2. Задайте **Папку загрузки**.

**Настройки:** `rclone` настраивается один раз командой `rclone config`, вход в аккаунт

**Ограничения / цена:** качает `rclone`, поэтому крупные файлы ему по силам; прогресс
разбирается из его статистики.
**Code:** `api/gdrive.py:449`, `api/gdrive.py:47`, `templates/index.html:32`

### Проект, число камер и очередь

**Где:** шаг 1 › **Проект**.
**Как:** 1. Задайте папку проекта. 2. Выберите число камер (от 1 до 4). 3. Выберите
файл каждой камеры. 4. Нажмите **В очередь** — или **Авто-пары по имени**, или
**Подбор по звуку**.
**Настройки:** **Подбор по звуку** ищет в папках камер 2..N файл того же дубля по
корреляции огибающих; порог снят с реальной съёмки, поэтому «похожего не нашлось» так и
означает «похожего нет». **Подбор всех по звуку** делает то же для всей папки камеры 1, а галка
**только новые** пропускает дубли, на которые в папке результата уже есть XML.
**Code:** `templates/index.html:49`, `api/files.py:57`, `core/sync.py:113`,
`core/sync.py:26`

### Синхронизация по звуку

**Где:** шаг 1 › **Проект** (переключатель **Камер**) — синхронизация идёт внутри нарезки.
**Как:** 1. Выберите 2 и больше камер. 2. Поставьте пары в очередь. 3. Звук сводится
кросс-корреляцией до нарезки.
**Настройки:** оффсеты пишутся в `<stem>.project.json` и видны в окне раскладки камер.
**Code:** `core/sync.py:82`, `core/sync.py:42`

### ИИ-нарезка

**Где:** шаг 1 › **Нарезка** › **ИИ-нарезка** (основная кнопка).
**Как:** 1. Заполните очередь. 2. Задайте папку результата. 3. Нажмите **ИИ-нарезка**.
**Настройки:** CTC-модель слушает файл целиком и отдаёт каждое слово с родными
таймингами. Дальше текстовая модель получает полную расшифровку и возвращает тот же
текст, заключив в квадратные скобки то, что надо выкинуть; код выравнивает этот ответ на
наши слова. Тишина дольше 0.8 с режется всегда. Модель и уровень «ума» задаются в ⚙ ›
**Нарезка**. Черновик mp4 собирается в конце каждой нарезки.
**Ограничения / цена:** провайдеру уходит только текст. В видеопамяти живёт одна тяжёлая
модель за раз, поэтому GigaAM выгружается до обращения к LLM.
**Code:** `core/gigaam_cut/asr.py:49`, `core/gigaam_cut/decide.py:26`,
`core/gigaam_cut/decide.py:169`, `core/gigaam_cut/pipeline.py:61`

### Кастомная нарезка и её ступени

**Где:** шаг 1 › **Нарезка** › **Кастом**; сами ступени — в ⚙ › **Нарезка** ›
**Ступени нарезки**.
**Как:** 1. Нажмите **Кастом**. 2. Отметьте нужные ступени в ⚙. 3. Запустите.
**Настройки:** ступени — один список, общий для бэкенда и интерфейса:

| Ступень | Что делает |
|---|---|
| **Паузы** | Вырезать паузы: по словам (речь), по энергии звука (громкость) или выключить |
| **Распознавание речи** | Пословные тайминги ASR; включается сам, если он нужен другой ступени |
| **Смысл (ИИ)** | LLM размечает смысловые куски и убирает неудачные дубли |
| **Правка нарезки кодом** | Код поверх ответа ИИ: повторы, оговорки, микро-островки; слабым моделям помогает, умным портит |
| **Подгон резов** | Точная подгонка точек реза по огибающей звука и границам слов |
| **Вздохи** | Детекция и вырезание вздохов перед фразами |
| **Черновик mp4** | Быстрый `.draft.mp4` для предпросмотра нарезки |

Выбор **Паузы → по громкости** переводит нарезку на классическую ветку: VAD плюс Whisper
вместо родных таймингов CTC. Пороги VAD (порог тишины, минимальная пауза, паддинг)
появляются на той же вкладке настроек.
**Ограничения / цена:** у ступени «Черновик mp4» отдельной галки в интерфейсе нет: она
включается вместе с Omni-ревью.
**Code:** `core/cutstages.py:16`, `core/cutstages.py:87`, `core/cutstages.py:149`,
`templates/index.html:801`, `static/app/10-settings.js:243`

### Детектор вздохов и полоска спорных вздохов

**Где:** шаг 1 › **Нарезка** (работает внутри нарезки), и полоска в редакторе нарезки.
**Как:** 1. Запустите нарезку. 2. Откройте редактор. 3. Клик по оранжевой полоске
вырезает этот вздох.
**Настройки:** профиль спикера может задать свои порог реза и порог метки; дефолты —
0.95 — вырезать, 0.50 — отметить. Участок с вероятностью речи выше 0.25 не режется
автоматически никогда. Переобучение — `python tools/train_breath.py`.
**Ограничения / цена:** решают три источника: Silero VAD, CED-tiny в изоляции и
акустика. Если нет `silero-vad`, `transformers` или файла модели, детектор молча
выключается, а нарезка идёт как раньше.
**Code:** `core/breath.py:40`, `core/breath.py:229`, `core/breath.py:254`,
`api/editor.py:135`

### Редактор нарезки

**Где:** шаг 1 › список клипов › **Правка** (окно предпросмотра, левая половина).
**Как:** 1. Откройте клип. 2. Клик ставит курсор, края блоков тянутся, двойной клик по

**Ограничения / цена:** сохранение переписывает XML и пересчитывает тайминги вставок под
новый монтаж; окно предупреждает, если закрывать с несохранённой правкой.
**Code:** `templates/index.html:306`, `static/app/70-editor.js:13`,

### Раскладка камер

**Где:** шаг 1 (строка клипа) › окно раскладки камер.

### Черновик mp4

### Список клипов

**Где:** шаг 1 › **Клипы**.
**Как:** 1. Кнопка **Из папки результата** подхватывает все `.xml` из папки выхода.
2. Кнопка **Добавить XML…** приносит таймлайн, поправленный в другой программе. 3. Метла
очищает список. 4. Отметьте клипы галками и нажмите корзину, чтобы удалить их.
**Настройки:** у каждого клипа есть галка выбора — та же, что в списках шага 2 и шага 3:

перерисовываются целиком, поэтому галка, с которой работали с клавиатуры, возвращается на
своё место в своём списке — Tab, пробел и выделение диапазона с Shift идут дальше по

**Убрать из списка** или **Удалить с диска…**; второе сначала показывает сводный список
файлов нарезки с их размерами, а потом стирает их вместе со всеми сайдкарами. Исходное
видео камер не трогается, и ошибка на одном клипе не мешает удалить остальные. Список живёт
в состоянии браузера и зеркалом на сервере, поэтому переживает перезагрузку и смену
браузера.
**Ограничения / цена:** пусто у всех здесь НЕ значит «все» (в отличие от сборки): удалять
нечего, поэтому кнопка остаётся погашенной.

`static/app/40-queue.js:720`, `api/files.py:534`

## Шаг 2 — разметка и вставки

### ИИ-разметка

### Субтитры

**Где:** шаг 2 (внутри разметки) и окно вставок › вкладка **Сабы**.
**Как:** 1. Запустите фазу субтитров. 2. Проверьте строки на вкладке **Сабы**. 3. Клик по
строке перематывает превью на неё.
**Настройки:** движок выбирается в ⚙ › **Разметка** › **Движок субтитров**. По умолчанию
Whisper large-v3; ещё предлагаются головы GigaAM: CTC — чистая акустика и быстро, RNN-T
правит слова своей языковой моделью, e2e RNN-T добавляет пунктуацию и регистр,
multilingual-модель покрывает 70+ языков. Слов в строке и максимум строк — ключи стиля с
полями на той же вкладке.

**Потолок увеличения интро, %** (`intro_fit_max`, 250): без потолка одно короткое слово
раздувалось до 667–819 % кадра, ужатие при этом не режется. Обе ручки видны только

строками интро.

того же межстрочного интервала. Ручек две, потому что видимые зазоры зависят от слов

**Большое слева.** Галка в строке интро ставит эту строку — одно слово или несколько — слева
крупно, а остальные строки группы собирает стопкой справа, по левому краю. Большое слово
стоит на базовой линии последней строки стопки, а высота считается по стопке: от верха

**Зазор до большого слова, px** (`intro_big_gap`, 40) — расстояние между большим словом и

## Ограничения

- Проверено только на Windows 11 с видеокартой NVIDIA и Adobe After Effects / Premiere
  Pro. Заметки о переносе на другие платформы: [docs/PLATFORMS.md](PLATFORMS.md).
- Цвет (Lumetri) в превью браузера — приближение: настоящие формулы Lumetri закрыты,
  поэтому превью показывает направление правки, а не точный результат.
- Tritone не ставится на яркий цвет жёлтого интро (яркость выше 0.7): на таком цвете он
  выбеливает свечение вместо того, чтобы его докрасить. Тёмные цвета акцентов его
  по-прежнему получают.
- У двух установленных шрифтов может совпасть PostScript-имя. Тогда сборка пробует копии и
  берёт ту, что действительно встала; если не встала ни одна, текст собирается шрифтом по
  умолчанию, а в лог уходит имя отвергнутого шрифта.
- Экспорт в Premiere XML и в `.drp` содержит известные дефекты:
  [docs/KNOWN_ISSUES.md](KNOWN_ISSUES.md).
- Статус бета-версии: структуры настроек и проектов могут меняться между релизами.
